# Reference: original design documents

The ~2019 beach-volleyball version of this game. Kept for lineage — the core market
mechanics carry over to the golf game, the sport does not. See `../design-decisions.md` for
what was kept, changed, or dropped.

Drop the original PDFs here:

- `Fantasy Beach Volleyball Game Design.pdf` — the full game-design writeup
- `Overall game architecture.pdf` — the data-model diagram (Investors / VBPlayer entities)
- `Buying Process.pdf` — flowchart: IPO, in-market buys, in-tournament buys
- `Selling Process.pdf` — flowchart: in-market sells, in-tournament sells, ghost stocks

These describe the **superseded** anti-freeze mechanic (share creation/destruction at
market ±1) and mid-match trading, both of which the golf design drops. Read them as history,
not spec.
